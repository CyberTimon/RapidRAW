# Contributing to RapidRaw

Thank you for your interest in contributing. We love community involvement and welcome your ideas, bug reports, and pull requests.

## Getting Started

1. **Fork the repository** and clone it locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/rapidraw.git
   cd rapidraw```

2. **Install dependencies** (see `README.md` for setup instructions).
3. **Create a new branch** for your feature or fix

## How to Contribute

* **Report bugs** using [GitHub Issues](https://github.com/YourUsername/rapidraw/issues).
* **Propose new features** by opening a discussion or issue first.
* **Submit pull requests (PRs)** once your code is ready.
  Please include a clear description and link to any related issue.

## Code Style

* Follow the existing code style and conventions.
* Use clear, self-explanatory commit messages.

## Documentation

If your contribution changes the public API or user experience, update the documentation accordingly.

## Community Guidelines

* Be respectful and constructive in discussions.
* Help others learn and grow.
* We value curiosity, transparency, and innovation.

---

### Need Help?

If you get stuck, open a discussion or reach out via the community channels listed in the README.
